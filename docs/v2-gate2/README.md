## Production artwork contracts

Fresh foreground requests use **`episode_illustration_v4`** and explicit
**`qwen_white_exterior_v3`** extraction. Foreground and scene-v3 environments consume
the same shared rounded-form, tonal-contour, gentle-shading, warm-light and controlled
palette direction, plus the catalog's episode art direction. Foreground prompts
remain subject-scoped and preserve natural anatomy. No shared location, fixed view,
scene template, topic classifier, new provider or new image model is introduced.

The V4 request profile fingerprints its exact visual-plan artifact ID/hash as well
as canonical prompt, translated existing Qwen workflow and normalization version.
Retained raw sources must match episode/slot/local/native/provider/model identity,
original plan dependency, immutable bytes and stored canonical/profile evidence.
Contradictory receipt metadata stops admission rather than being ignored.

Historical illustration V2/V3 specs and fingerprints remain exact. A returned,
plan-bound source can finish admission through the new default using its original
prompt/profile/extraction contract, only after complete fingerprint equality.
Selected historical assets keep their existing reuse path. Sources from another
plan, changed inputs, unknown/ambiguous results without retained source evidence,
and legacy prepared requests cannot be silently converted into a new request.
V2 illustrations retain exterior V1; V3 illustrations retain exterior V2; new V4
illustrations use exterior V3. No old production data is rewritten or reselected.

An explicit immutable Gate 1 retry authorization also retains its parent's V2/V3
contract, including a definitive-failure retry or an exceptionally authorized native
crash successor. Parent/successor identity, attempt and complete stored profile must
agree. This does not grant a retry or alter the parent; the original ownership,
returned-evidence and fresh native-crash rechecks still run at the submission
boundary. Ungranted legacy prepared/unknown requests remain blocked. Regressions
exercise the original Gate 1 assertions with old V2/V3 requests, including stale
queue/receipt rejection before any new POST.

The original Gate 1 flow still retains raw returned bytes before ingestion and the
lease fence, preserving evidence even after ownership loss. Normalization, preview
admission, selection and final receipt changes remain fenced. `before_submit`
remains on the actual-submission path; valid source/response reuse does not start
services or send another POST. Native-crash parents, successor attestations,
accepted native IDs and unknown-outcome safeguards are unchanged.

A source failing extraction is retained with its source artifact ID, exact
normalization version and actionable reason; no visual asset or raw preview
selection is admitted for that failed attempt. Repeated local admission attempts
reuse evidence and do not submit to Qwen. No mask growth, deleted specks, repainting
or automatic source replacement occurs.

Exterior V3 rejects crop bounds supported only by detached source components of
at most four pixels, including V2's two-pixel/2x2 noise gap. Eight-connectivity keeps
attached diagonal tips and meaningful detached parts. V1/V2 bytes remain frozen.
Pale parts enclosed by a distinct contour survive; indistinguishable white sources
are refused. Component size is a technical padding guard, not an editorial score.
