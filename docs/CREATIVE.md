# Creative domain

`CreativeService` supplies the preschool-specific stages inside `Orchestrator.generate` / `resume`: TopicPlanner, a selected immutable LearningBrief, EpisodeSpec, LyricsSpec and MusicSpec. Pins, safety policy, cast, vocabulary and duration validation remain ToviTunes contracts. Prompts live in `creative/prompts.py`.

NVIDIA NIM uses the configured ordered Kimi, GLM, Nemotron, DeepSeek chain. Generation/read uses `creative_llm.timeout_seconds` unchanged; connection establishment is bounded to `min(timeout_seconds, 15)`. NVIDIA runtime retries follow the pinned donor: connect/DNS delays `(2, 5, 15)`, HTTP server/throttling delays `(2, 5)` (bounded Retry-After up to 30 seconds), and read timeout/interrupted stream delay `(2,)`. Each issued request has a fresh durable UUID and a `previous_attempt_id` link. Each model retains at most one durable schema/domain repair. Successful fallback is sticky across stages and process restarts. The single classifier in `creative/failures.py` assigns MODEL, ENDPOINT or FAIL_CLOSED; optional Ollama handles eligible endpoint failure only.

Historical ambiguous creative requests remain immutable and automatically advance to the next configured model after restart; they never authorize retries. Only a typed transient failure observed during the currently executing attempt can authorize a bounded fresh runtime request. A crash during the retry delay loses that permission; a prepared but unstarted retry may resume safely. No manual reconciliation participates in new production. Authentication, configuration and unexpected programming failures fail closed. Old PR40 reconciliation rows can be inspected with `creative request-status` and remain immutable historical evidence.

`creative generate-next --live` delegates to the application DRAFT target. Existing episode generation delegates to `resume(..., DRAFT)`. `creative doctor`, `creative history`, `creative eligible` and `creative request-status --request-id ...` are read-only inspection commands. Metadata is the RENDER target's final domain stage.

Historical curriculum branches only read or migrate already persisted Colors identity; new autonomous production always uses open topic planning.
